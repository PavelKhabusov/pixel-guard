What it does

Everything DevTools and a ruler do — automated

Every element is checked against its Figma node: typography, colours, spacing, size and position. Differences come back named, not as a percentage of pixels.

Element-by-element

Computed CSS and geometry of each mapped element against the node in the snapshot. Per-property tolerances, per-node ignores.

No REST API in the loop

The Figma plugin walks the file through the Plugin API and writes a JSON snapshot. No tokens, no 429s, works with any file you can open.

Three breakpoints

Desktop, tablet and phone through CDP device emulation. The browser window never resizes.

Agent-native

An MCP server exposes node styles, renders and the checker. Claude Code fixes CSS without a Figma tab.

› figma_get_node_styles hero/title
‹ font-size 56px · weight 700 · lh 1.1
› run_qa --page home
✕ 1 mismatch · .hero h1 font-size
› edit styles.css:41 → 56px
✓ 42/42 match

CSS patch from diffs

npm run patch turns mismatches into a proposed patch you review before applying.

/* home @ desktop */
.hero h1 {
- font-size: 52px;
+ font-size: 56px;
}

Design overlay & curtain

Rendered PNGs of design blocks laid pixel-aligned over the page. A curtain splits the screen — the same one in the hero above.

Maps you can read

A node ↔ selector map per page, shared blocks once. automap writes most of it; verify --fix catches selectors that stopped matching.

"hero/title": { "selector": ".hero h1" },
"hero/lead":  { "selector": ".hero p", "tolerance": { "line-height": 0.05 } },
"hero/badge": { "skip": "rendered by JS" },
"@header":    "_shared"
How it works

Figma once. Everything else from disk.

The snapshot is a plain JSON you can commit. CLI, browser panel and the MCP server all read the same file.

01

Capture

Select frames in Figma, press Capture. Or export the whole project in one go — pages plus shared modules.

02

Map

npm run automap pairs nodes with selectors; the rest is a click in the panel or a line in maps/page.map.json.

03

Check

npm run qa in CI, Check page in the browser, or let an agent do it over MCP. Same report either way.

Why not screenshots

Same bug, two reports

A heading rendered at 52px instead of 56px.

Screenshot diff any pixel tool
  • 3.4 % of pixels differ
  • Everything below the heading shifted — the whole block lights up
  • Anti-aliasing and hinting add noise on every run
  • To fix it: open DevTools, open Figma, measure by hand
pixel-guard per-element
✕ hero/title  .hero h1
   font-size   56px → 52px
✓ 41 other properties match
  • 1 mismatch, named: node, selector, property, both values
  • Downstream layout shifts are not reported twice
  • Deterministic — same DOM, same report
  • The fix is one CSS line, no Figma needed

$ npm install
$ ./start.sh            # Figma ↔ browser bridge + panel
