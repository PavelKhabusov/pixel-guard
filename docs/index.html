How the data moves

Figma is touched once, by the plugin. Everything after that works from the snapshot on disk — CLI, browser panel and the MCP server for agents read the same file.

Why not just diff screenshots

Same bug — a heading rendered at 52px instead of 56px — seen by a pixel-diff tool and by pixel-guard.

Screenshot diff any pixel tool
  • 3.4 % of pixels differ
  • Everything below the heading shifted, so the whole block lights up
  • Anti-aliasing and font hinting produce noise on every run
  • To fix it you open DevTools and the Figma file and measure by hand
pixel-guard per-element
✕ hero/title  .hero h1
   font-size   56px → 52px
✓ 41 other properties match
  • 1 mismatch, named: node, selector, property, both values
  • Layout shifts downstream are not reported twice
  • Deterministic — same DOM, same report
  • The fix is a one-line CSS change you can make without opening Figma

Anatomy of a map

A map ties Figma nodes to CSS selectors. npm run automap writes most of it; the rest is a click in the panel or a line by hand.

{
  "match": ["/", "/index.html"],                 1
  "nodes": {
    "hero/title": { "selector": ".hero h1" },       2
    "hero/lead": {
      "selector": ".hero p",
      "tolerance": { "line-height": 0.05 },        3
      "ignore": ["color"]
    },
    "994:13213": { "selector": ".hero .btn" },      4
    "hero/badge": { "skip": "rendered by JS later" }, 5
    "@header": "_shared"                              6
  }
}
1URL match — the panel picks the right design for the page you have open. No Figma tab needed.
2Node by name path — frame/child as in the Figma layers panel.
3Tolerance and ignore per property — accept sub-pixel line-height, skip colours a theme controls.
4Node by id when names are unstable — straight from the URL, 994-13213 → 994:13213.
5Skip with a reason — stays visible in the report instead of silently disappearing.
6Shared modules — header, footer and other cross-page blocks live in _shared.map.json once.

Also in the box

Design overlay

Rendered PNGs of design blocks laid pixel-aligned over the page, with the curtain you dragged above.

Live bridge

Optional: click a node in Figma, the panel highlights its element on the site — and back.

Whole-project export

One button snapshots every page at once; _project.json lists pages and shared modules.

Pixel diff, when you want it

npm run pixdiff for the cases where a raster comparison is the right tool.

Map verification

npm run verify -- --fix catches selectors that stopped matching after a refactor.

Agent-native

MCP tools: read node styles, render a node, find nodes, run the check — Claude fixes CSS without opening Figma.

Install

Node ≥ 20, Chrome, Figma desktop app for snapshots.

$ git clone https://github.com/PavelKhabusov/pixel-guard && cd pixel-guard
$ npm install
$ ./start.sh            # Figma ↔ browser bridge + panel

# Figma  → Plugins → Development → Import plugin from manifest… → plugin/manifest.json
# Chrome → chrome://extensions → Load unpacked → extension/
